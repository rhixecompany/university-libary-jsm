## Data Flow
1. Browser → Next.js App Router (`app/(root)`, `app/admin`) renders server components.
2. Mutations hit `app/api` route handlers → Drizzle ORM → Neon Postgres.
3. User sessions are cached in Upstash Redis; repeated/rapid requests are throttled (surfacing `app/too-fast`).
4. Auth state resolved by `auth.ts` / NextAuth; unauthorized users routed to `app/unauthorized`.
5. Schema changes applied via `npm run db:push` (Drizzle); inspected via Drizzle Studio.
